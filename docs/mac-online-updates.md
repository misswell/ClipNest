# macOS 在线更新

实现参考 MacPilot 和 DevSweep 的独立安装程序方案，沿用 ClipNest 现有 GitHub Release、Developer ID 签名和公证流程。

- 菜单「ClipNest → 检查更新…」和设置页「软件更新」可手动检查。
- 自动检查默认开启，在应用启动时每天最多检查一次；用户选择「下载并重启」后才安装。
- 只接受 `misswell/ClipNest` 的稳定最新版和精确匹配的 `ClipNest-<version>-macos.zip`。按数字比较版本，不安装相同或更低版本。
- GitHub 资产必须提供 SHA-256 digest。下载会校验长度和哈希，再检查归档路径、解压后大小、应用标识、版本、处理器架构、系统要求、完整签名和 Gatekeeper。
- Developer ID 固定为现有发布使用的 `U8U443D7ZL`。签名团队迁移需要另行设计信任迁移，不能仅修改 CI 的签名账号。
- 下载和验证可取消。安装前禁用编辑并刷新编辑器待保存内容；保存失败或超时会阻止退出。
- `ClipNestUpdater` 是嵌入 `Contents/MacOS` 的通用命令行程序。启动前复制到独立临时目录，等待父进程退出，再在同一卷内保留旧版、替换并启动新版。启动失败恢复旧版；恢复失败保留备份并在下次打开时显示其位置。
- 无管理员提权：应用及其所在目录必须可写。转移隔离路径、符号链接路径或只读位置不会自动安装。

## 构建与发布

`project.yml` 为 macOS 添加安装程序目标与嵌入依赖，iOS 不包含该程序。新增源文件后运行 `xcodegen generate`。

`Scripts/distribute-app.sh` 先签名安装程序，再签名外层应用，验证其架构、嵌套签名和固定的开发者身份；现有 GitHub Release 工作流进一步验证安装程序签名及 arm64/x86_64 架构。发布前按项目既有流程更新 `MARKETING_VERSION` 并发布对应稳定标签。

此前没有更新模块的版本，需要先手动安装一个包含更新模块的新版本，之后才能使用应用内更新。本地测试使用临时夹具覆盖版本判断、异常包拒绝、替换、回滚和笔记保存阻塞。稳定版发布时另行核验实际下载包的版本、架构、签名、公证和票据。
